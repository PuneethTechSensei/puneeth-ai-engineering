LEARNER ACCOUNTS

Supabase

Optional accounts can sync progress and assessments. The browser must use only the project's publishable key; never place a service-role/secret key in the website.

  1. Create a free Supabase project.
  2. Run supabase-setup.sql.
  3. Copy the project URL and publishable key into supabase-config.js.
  4. Deploy again through GitHub → Vercel.
