# PromptFix V8 — Editorial Standard

Every lesson must teach a concrete capability, not merely describe a topic. Each lesson contains: problem/why, mental model, worked example, hands-on experiment, deliberate failure, proof artifact, transfer, common mistakes, and current/primary references where useful.

## Quality gates
1. No generic fallback copy.
2. Lesson title and content must match exactly.
3. One transferable capability per lesson.
4. Learner performs an observable task.
5. Learner deliberately breaks or challenges an assumption.
6. Learner records evidence that can be reproduced.
7. Assessment tests application/diagnosis, not only vocabulary.
8. Fast-moving topics carry a freshness note and official reference.
9. Optional phases never block the core path.
10. Page copy explains the learning loop rather than pretending scaffolding is teaching.

## Editorial rule
If a learner can mark a lesson complete without producing evidence, diagnosing a failure, or making an engineering decision, the lesson is not ready.
