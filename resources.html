BEST WAY TO USE THIS LIBRARY

A practical learning sequence

01 · UNDERSTANDStart with LLMs and agent fundamentals

Watch one introductory video, then explain the model/tool distinction in your own words before moving on.

02 · INSPECTRead and run a real repository

Choose one repo, follow its README, run a small example, and record setup steps plus one failure you diagnosed.

03 · ENGINEERApply the production guides

Use evaluation, tool boundaries, observability, and failure handling as a checklist—not just reading material.

Learning rule: Don't try to consume everything. Pick one resource that matches your current lesson, produce a small artifact, and write down what you verified. External links can change; the core curriculum remains the learning path.
