PRIVACY PRINCIPLES

Learn freely. Collect only what helps.

The core curriculum remains usable without an account. Analytics should help improve the learning experience, not become a barrier to access.

What is measured

  • Vercel Web Analytics can provide aggregated site traffic such as visitors and page views.
  • Optional learner accounts store progress and assessment state so it can sync across devices.
  • Authenticated learning events are used only to understand the learner's own activity unless a future privacy policy says otherwise.

What we avoid

  • No learner payment requirement for core education.
  • No service-role or database secret in browser code.
  • No unnecessary personal profile fields.
  • No selling learner information.
This is a project-level privacy statement, not legal advice. Before public scale, review it against the jurisdictions and services you actually use.
