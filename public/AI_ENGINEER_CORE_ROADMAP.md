# AI Engineer Core Roadmap — Puneeth AI Engineering

This curriculum is designed to take a beginner toward practical AI engineering without assuming an expensive bootcamp, paid API access, or prior ML expertise.

## Core skill stack

1. Software engineering — Python, Git, CLI, testing, APIs, packaging, debugging
2. Data + math — vectors, matrices, probability, statistics, optimization
3. Classical ML — datasets, leakage, splits, baselines, supervised learning, metrics, tuning
4. Deep learning — tensors, neural networks, autograd, optimization, debugging, PyTorch
5. Language + representation — NLP, embeddings, attention, transformers
6. Generative AI — inference, prompting, structured outputs, tool calling, context management
7. RAG — ingestion, chunking, embeddings, hybrid retrieval, reranking, grounding, evaluation
8. Agents — tools, state, memory, orchestration, recovery, human approval, evaluation
9. AI systems — APIs, async work, queues, caching, idempotency, failure handling
10. LLMOps/MLOps — experiment tracking, versioning, CI/CD, tracing, evaluation, monitoring, cost
11. AI Quality Engineering — regression datasets, deterministic tests, LLM judges, human review, quality gates
12. Security + responsible AI — prompt injection, privacy, access control, supply chain, threat modeling, risk management
13. Production — containers, serving, model optimization, observability, release/rollback
14. Portfolio — end-to-end systems with tests, evaluation, documentation and architecture decisions

## Core vs specialization

The platform should teach the skills needed by a broad AI Engineer first. Computer vision, multimodal systems and advanced research topics are valuable, but should not block a learner from becoming productive in LLM/application AI engineering. They remain part of the curriculum as specialization modules.

## Learning rule

Every phase follows: Learn → Experiment → Build → Break → Prove → Progress. A learner should be able to explain the concept, implement a minimal example, test or evaluate it, and describe at least one production failure mode before moving forward.
